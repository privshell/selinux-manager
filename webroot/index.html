Safe tests

    
Ways to try the risky parts without leaving anything behind.

    
Permissive for 60 secondsSwitches back to enforcing by itself, even if this page is closed.

    
Boot guard testMakes the next normal boot count as the third unfinished one. The phone boots as usual, the module disables itself and says the guard worked. Enable it again in the manager afterwards.

    
Test file for labelsCreates a file in /data/local/tmp and puts it in the Files tab, so chcon and restorecon can be tried on something harmless.

    
Trial rulesRules editor > Trial next boot: the editor's rules are applied once after the next boot and then forgotten. The boot after that is clean. Saved rules are not touched.
